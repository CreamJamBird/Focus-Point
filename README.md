# Точка фокуса

Читалка в стиле Spritz (RSVP): слова показываются по одному в одной точке экрана, а точка оптимального распознавания подсвечена красным. Глазам не нужно прыгать по строке, поэтому читать можно заметно быстрее.

## Возможности

- Скорость от 100 до 1200 слов в минуту, плавный разгон после старта.
- Умные паузы на запятых, концах предложений и абзацев, длинных словах.
- Миникарта текста вокруг текущего слова: нажмите на любое слово, чтобы перейти к нему.
- Открытие TXT (UTF-8 и windows-1251), PDF и EPUB, переход по главам из оглавления книги.
- Позиция, скорость и настройки запоминаются в браузере.

## Управление

| Клавиша | Действие |
|---|---|
| Пробел | Старт / пауза |
| ← / → | Предыдущее / следующее предложение |
| ↑ / ↓ | Скорость ±25 слов в минуту |

## Запуск

Сборка не нужна, каждая версия приложения находится в одном файле:

- `index.html` — стартовая страница с выбором языка;
- `index.ru.html` — интерфейс на русском;
- `index.en.html` — интерфейс на английском.

Откройте `index.html` в браузере или включите GitHub Pages. Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `root`.

Для чтения PDF и EPUB используются [pdf.js](https://mozilla.github.io/pdf.js/) и [JSZip](https://stuk.github.io/jszip/), они подгружаются с cdnjs при первом открытии такого файла.
